# Project agent instructions

Item Teach and headless Item Detect provide read-only pose generation. Rule 51 enables explicit-action robot_controller Home/pick execution, superseding historical non-actuating controller restrictions; complete command-ownership migration remains pending.

Before making changes, read [`docs/WORKFLOW_RULES_BLUEPRINT_DIARY.md`](docs/WORKFLOW_RULES_BLUEPRINT_DIARY.md) and the root `README.md`. Treat the diary as the project handoff document when an agent or contributor changes.
